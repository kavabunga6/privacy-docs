График смен: Сменка

Политика конфиденциальности

Действует с 17 августа 2026 года. Приложение ru.kava.work_schedule предназначено для личного ведения рабочего графика и ориентировочного расчёта дохода.

Коротко

Сменка работает офлайн. Приложение не требует регистрации, не отправляет введённые данные разработчику и не содержит аналитических или рекламных SDK.

Какие данные обрабатываются

Пользователь может самостоятельно ввести:

  • график, даты, плановое и фактическое время смен и перерывов;
  • названия мест работы, ставки и пользовательские шаблоны смен;
  • премии, удержания, заметки и ориентировочные параметры налогового расчёта;
  • настройки напоминаний.

Приложение не запрашивает имя, номер телефона, аккаунт, платёжные реквизиты или точную геолокацию.

Хранение и резервные копии

Данные хранятся локально в закрытом хранилище приложения на устройстве. Разработчик их не получает и не просматривает.

Android может включить данные приложения в системную резервную копию аккаунта, если эта функция включена на устройстве. Пользователь также может вручную создать файл резервной копии. Место сохранения выбирается в системном окне Android; при выборе Google Drive или другого облачного сервиса обработка файла регулируется правилами выбранного сервиса.

Файл резервной копии содержит введённые пользователем сведения и не шифруется отдельным паролем внутри приложения. Пользователь самостоятельно отвечает за безопасное место его хранения.

Экспорт и передача

CSV-отчёт и резервная копия передаются другому приложению только после явного действия пользователя через системное меню Android. Сменка не загружает эти файлы на сервер разработчика.

Разрешения

  • Уведомления — для выбранных напоминаний о сменах.
  • Запуск после перезагрузки — чтобы заново запланировать включённые напоминания.

У приложения нет разрешения на доступ к интернету.

Внешние ссылки

Раздел «О приложении» содержит ссылки на Boosty, электронную почту и эту политику. Они открываются только по нажатию и обрабатываются выбранным браузером или почтовым приложением согласно их правилам.

Удаление данных

Локальные данные можно удалить через системные настройки Android («Очистить данные») или удалив приложение. Созданные вручную резервные копии и CSV-файлы необходимо удалить отдельно из выбранного хранилища.

Дети и изменения политики

Приложение не предназначено для целевого сбора персональных данных детей. При изменении способов обработки данных новая редакция будет опубликована по этому же адресу с новой датой.
