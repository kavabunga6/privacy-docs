«Пауза» работает без аккаунта, рекламы, аналитики, облачной синхронизации и серверов разработчика. Данные приложения остаются на устройстве.

О политике

Настоящая политика описывает обработку данных в Android-приложении «Пауза» (app.gateway.focus). Разработчик не получает, не продаёт и не передаёт данные приложения третьим лицам.

Какие данные используются на устройстве

Для работы функций приложение локально хранит:

  • выбранные пользователем приложения;
  • время начала и окончания активной фокус-сессии;
  • длительность фокуса и настройки интерфейса;
  • количество остановленных открытий и статистику по дням и приложениям;
  • временное разрешение открыть выбранное приложение;
  • состояние онбординга и показа подсказок.

Эти сведения не отправляются разработчику и не используются для рекламы или создания профиля пользователя.

Специальные возможности Android

Пользователь может добровольно включить службу специальных возможностей, чтобы «Пауза» определяла, какое приложение находится на переднем плане во время активной фокус-сессии. Если открыто выбранное отвлекающее приложение, «Пауза» показывает экран с вопросом о цели открытия.

Служба не получает содержимое окон, не читает текст, сообщения, уведомления, пароли или нажатия клавиш, не делает снимки экрана и не выполняет действия от имени пользователя. Имя открытого приложения обрабатывается только на устройстве и не передаётся разработчику или третьим лицам. Доступ можно отключить в настройках специальных возможностей Android.

Уведомления и режим «Не беспокоить»

Разрешение на уведомления используется для постоянного таймера фокуса и сообщения о завершении сессии. Доступ к режиму «Не беспокоить» используется только по выбору пользователя, чтобы приглушить уведомления на время фокуса и восстановить прежнее состояние после завершения.

Отображение поверх других приложений

Необязательное системное разрешение «Поверх других приложений» используется только для небольшого перемещаемого таймера. Таймер не анализирует и не сохраняет содержимое под ним. Функцию и разрешение можно отключить в любой момент.

Передача данных и внешние ссылки

Приложение не запрашивает разрешение на доступ в интернет и не передаёт пользовательские данные на серверы разработчика. При переходе по добровольной ссылке поддержки открывается внешний сайт Boosty в браузере или его приложении; дальнейшая обработка регулируется политикой Boosty.

Резервное копирование Android

В зависимости от настроек устройства Android может включать локальные настройки приложения в системную резервную копию пользователя. Этот процесс выполняется операционной системой и выбранным пользователем поставщиком резервного копирования. Разработчик приложения не получает доступа к такой копии.

Хранение и удаление

Данные хранятся на устройстве, пока пользователь не очистит данные приложения или не удалит приложение. Отдельного аккаунта и серверной копии не существует, поэтому запрос на удаление аккаунта не требуется.

Дети

Приложение не предназначено специально для детей и не собирает сведения о возрасте.

Изменения политики

Если возможности приложения или способы обработки данных изменятся, политика будет обновлена до публикации соответствующей версии. Актуальная дата указывается в начале страницы.

Privacy Policy for Pause

Effective date: August 25, 2026

This policy explains how the Pause Android application (app.gateway.focus) handles data. Pause works without an account, advertising, analytics SDKs, cloud sync, or developer-operated servers. App data is processed and stored locally on the device. The developer does not receive, sell, or share this data with third parties.

Data used on the device

To provide its features, Pause locally stores apps selected by the user, focus session start and end times, focus duration and interface preferences, counts and statistics of paused openings, temporary permission to open an app, and onboarding or help prompt state. This information is not sent to the developer and is not used for advertising or user profiling.

Android Accessibility Service

The user may voluntarily enable an Accessibility Service so Pause can identify which app is in the foreground during an active focus session. When a selected distracting app is opened, Pause displays a screen asking why the user is opening it.

The service cannot retrieve window content. It does not read text, messages, notifications, passwords, or keystrokes, take screenshots, or perform actions on the user's behalf. The foreground app name is processed only on the device and is not sent to the developer or third parties. The user can disable access at any time in Android Accessibility settings.

Notifications and Do Not Disturb

Notification permission is used for the ongoing focus countdown and the focus-complete notification. Do Not Disturb access is optional and is used only when requested by the user to quiet notifications during a focus session and restore the previous state afterward.

Display over other apps

The optional Display over other apps permission is used only for a small movable countdown timer. The timer does not inspect or save content underneath it. The feature and permission can be disabled at any time.

Data transmission and external links

Pause does not request internet access and does not transmit user data to developer-operated servers. If the user follows the optional support link, the external Boosty website opens in a browser or its app; subsequent data handling is governed by Boosty's privacy policy.

Android backup

Depending on device settings, Android may include local app preferences in the user's system backup. This process is controlled by the operating system and the user's chosen backup provider. The app developer cannot access that backup.

Retention and deletion

Data remains on the device until the user clears the app's storage or uninstalls the app. There is no account or server copy, so no account deletion request is required.

Children

Pause is not specifically directed to children and does not collect age information.

Changes to this policy

If the app's functionality or data handling changes, this policy will be updated before the corresponding version is released. The current effective date appears at the top of this page.
